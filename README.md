# ExcelParcer

## Описание проекта

**ExcelParcer-Worked** — настольное приложение на языке **Python**, предназначенное для автоматического заполнения корпоративного шаблона Excel на основании данных из другой Excel-таблицы.

Основная задача программы — автоматизировать перенос финансовых данных между таблицами, исключить ручной ввод информации, сократить время подготовки отчетности и минимизировать вероятность ошибок.

Приложение обладает графическим интерфейсом, разработанным с использованием **Tkinter**, благодаря чему пользоваться программой можно без специальных знаний в области программирования.

---

# Основные возможности

Программа позволяет:

- выбрать Excel-файл с исходными данными;
- выбрать Excel-шаблон для заполнения;
- автоматически определить отчетный период;
- найти необходимые строки и столбцы шаблона;
- распределить данные по разделам отчета;
- автоматически заполнить соответствующие ячейки Excel;
- отображать прогресс выполнения операции;
- уведомлять пользователя о найденных ошибках.

---

# Принцип работы

Работа приложения состоит из нескольких этапов.

## 1. Запуск программы

После запуска открывается главное окно приложения, в котором доступны следующие действия:

- выбор файла с исходными данными (F2);
- выбор Excel-шаблона (НЗО);
- запуск процесса заполнения;
- просмотр инструкции;
- просмотр информации о разработчиках.

---

## 2. Загрузка файлов

Пользователь выбирает два Excel-файла.

### Исходный файл

Содержит финансовые данные предприятия.

Из файла считываются:

- направления деятельности;
- статьи расходов;
- суммы;
- дата формирования отчета.

Для чтения используется библиотека **pandas**.

---

### Шаблон

Представляет собой заранее подготовленный Excel-документ, который необходимо автоматически заполнить.

Для работы с шаблоном используется библиотека **openpyxl**, позволяющая изменять существующий документ без нарушения его структуры и форматирования.

---

## 3. Обработка даты

Программа автоматически определяет отчетный период.

Класс `Data` выполняет:

- преобразование даты;
- определение текущего месяца;
- вычисление следующего месяца;
- перевод названия месяца на русский язык;
- формирование подписей вида:

```text
1 января 2025
```

Полученные значения используются при поиске необходимых столбцов в шаблоне.
---

## 7. Работа с Excel

Основная логика записи данных реализована в классе `push_excel`.

Он выполняет:

- поиск строк;
- поиск столбцов;
- запись значений;
- суммирование значений при повторной записи;
- поиск разделов шаблона.

Для ускорения работы часть результатов поиска кэшируется.

---

## 8. Алгоритм заполнения

Во время работы программа:

1. открывает шаблон Excel;
2. открывает файл с исходными данными;
3. определяет отчетный период;
4. находит необходимые столбцы;
5. определяет строки разделов;
6. последовательно вызывает специализированные обработчики;
7. записывает данные в шаблон;
8. сохраняет изменения;
9. уведомляет пользователя о результате выполнения.

---

# Контроль ошибок

Во время обработки программа отслеживает возможные ошибки.

Если не удается найти необходимую строку, раздел или колонку, информация сохраняется в список ошибок.

После завершения обработки пользователю отображается перечень всех незаполненных позиций.

При успешном завершении выводится сообщение:

```text
Файл успешно заполнен.
```

# Особенности реализации

Проект построен по модульному принципу.

Каждый раздел финансового отчета обрабатывается отдельным модулем, что обеспечивает:

- разделение ответственности между компонентами;
- простоту сопровождения;
- удобство расширения функциональности;
- возможность независимой доработки отдельных модулей;
- повторное использование кода.
